# 🧩 Плагіни для Lampa

Колекція користувацьких плагінів для застосунку Lampa.

## 🚀 Як встановити
1. Перейдіть у **Налаштування** -> **Розширення/Додатки** у Lampa.
2. Натисніть **Додати плагін**.
3. Вставте посилання на потрібний `.js` файл зі списку нижче та збережіть.
4. Перезапустіть застосунок.

---

## 📦 Список плагінів

### 🗄️ Cache Editor (Редактор Кешу)
Потужний інструмент для керування локальним сховищем: очищення сміття, кошик для відновлення видалених даних, редагування таймкодів та пошук дублікатів.
* **Посилання для Лампи:** `https://n1kk1-08.github.io/lampa-plugins/cache_editor.js`

### 🤖 AI Search
Пошук з використанням ШІ без ассистента.
* **Посилання для Лампи:** `https://n1kk1-08.github.io/lampa-plugins/ai_search.js`

### 💬 AI Search Assistant
AI Ассистент + AI пошук.
* **Посилання для Лампи:** `https://n1kk1-08.github.io/lampa-plugins/ai_search_assistant.js`

### 📊 Lampa Stats
Статистика переглядів та метрики.
* **Посилання для Лампи:** `https://n1kk1-08.github.io/lampa-plugins/lampa_stats.js`

### 🏅 Release Badges
Відображення плашок/бейджів якості релізів.
* **Посилання для Лампи:** `https://n1kk1-08.github.io/lampa-plugins/release-badges.js`

### 🎨 MyLampa skin
Окремий плагін оформлення **v0.4.3** для Lampa. Підключається за бажанням через розширення.

- Вісім стилів: MyLampa, Netflix, AMOLED, Glass, Neon, Aurora, Nord та Velvet — з різними фонами, прозорістю, формою й свіченням. Єдиний колір теми та ручне налаштування підсвітки.
- Великий банер «В центрі уваги» на головній, у фільмах і серіалах; окреме ввімкнення для кожної вкладки. Джерело — штатне TMDB/КіноБаза.
- Горизонтальний блок продовження перегляду зі збереженим прогресом, годинник із датою та днем тижня.
- Розмір інтерфейсу 90–150%, включно з великими варіантами для ТВ. На сторінці релізу верхня панель може ховатися та виїжджати при переході вгору, прокручуванні чи наведенні на верхній край.
- Редаговані верхні кнопки й бічне меню для пунктів інших плагінів. Меню можна приховати та відкривати стрілкою вліво з краю контенту або натисканням на логотип.
- Компактні кольорові плашки окремими рядками: серії, наступна серія, тривалість фільму/серії; сезони й жанри нижче. Кольорові іконки дій та рамки торентів і бітрейту.
- Сумісність із Release Badges: метки якості зберігаються, оцінки на постерах залишаються у звичному оформленні.

**Налаштування:** Налаштування → **MyLampa skin** (іконка палітри).
